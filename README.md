# 🌤️ Weather App

Aplicación web desarrollada con **React** que muestra el clima actual de cualquier ciudad del mundo. Consume una API meteorológica para obtener datos en tiempo real como la temperatura, la descripción del clima y el icono correspondiente.

## ✨ Características

- 🔍 Búsqueda de clima por nombre de ciudad
- 🌡️ Temperatura actual, descripción y icono del clima
- ⚡ Datos actualizados en tiempo real mediante API externa
- 📱 Interfaz sencilla y limpia

## 🛠️ Tecnologías utilizadas

- **React**
- **JavaScript**
- **OpenWeatherMap**
- **CSS**

## 🚀 Instalación y uso

Clona el repositorio e instala las dependencias:

```bash
git clone https://github.com/marcalvarez-dev/weather-app
cd weather-app
npm install
```

Ejecuta la aplicación en modo desarrollo:

```bash
npm run dev
```
